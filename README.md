# RITA Point Cloud Desktop

**Reconstruction, Pose Inference, Tracking, and Alignment**

RITA Desktop captures live RealSense RGB and depth on supported systems, displays 3D point clouds, and saves and opens PLY models.

![RITA Point Cloud Desktop v0.2.0](https://github.com/javiergs/rita-desktop/blob/fa08d2ff6c4adb7baf66c1b67d951d2880199098/assets/rita-desktop-screenshot.png)

## Downloads

Get the installer for your platform from [GitHub Releases](https://github.com/javiergs/rita-desktop/releases/latest).

- **macOS on Apple Silicon** — DMG for PLY viewing and RealSense capture.
- **Windows x64** — MSI for PLY viewing.

## Sample captures

Download [robot.ply](samples/robot.ply) or [room.ply](samples/room.ply), then choose **Open Model** in RITA. The samples can be viewed without a camera.

This repository contains RITA Desktop downloads and sample captures.
